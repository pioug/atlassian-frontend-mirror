## Usage

Use a filter button to let people refine a list, board table or search results. It’s often used as a
dropdown menu trigger. Its count shows how many filters or selections are active, so people can see
that filters are applied even when the menu is closed.

1. **Icon (optional):** A leading icon that reinforces the filter action.
2. **Badge (optional):** The trailingMetric prop can be used to show how many filters or selections
   are active.
3. **Label:** Text describing what the button filters, such as “Filter”, “Status” or “Assignee”.
4. **Dropdown icon (optional):** Indicates affordance to open a filter menu.

## Default vs selected filter button

A filter button has two main appearances. Use them accordingly.

**Default:** Use the default appearance for system set filters. For example, this can include a view
with no filters, or one that loads with filters already applied. Also use it when someone resets the
view to its preset filters.

**Selected (`isSelected`):** Use the selected filter button when a user has applied or changed the
filter, for example by choosing statuses or removing a preset assignee. Keep the button selected
while those filters are applied, even after the menu closes.

## Best practices

### Use the trailing metric to show active filters

The trailing metric badge should be a number that helps people understand the current filtered view,
usually the number of filters applied. The value is a string, so you can pass formatted values like
`99+`.

### Ensure filter actions are clear

Because the icons are optional, ensure filter actions are always clear. Use a label that helps
people recognize the button as a filter, not a general action. When there’s no icon, ensure the
label and surrounding context communicate its purpose.

## Accessibility

- Don’t rely on the count or selected color alone to show filters are applied. Make sure assistive
  technology announces the filter state, for example “Status, 2 filters applied”.
- Don’t disable filter buttons to show that no filters are available. Disabled buttons can’t be
  focused or reached by keyboard use, and they don’t explain why.
- When used as a dropdown trigger, pass on the trigger props so the expanded state and focus are
  announced.
