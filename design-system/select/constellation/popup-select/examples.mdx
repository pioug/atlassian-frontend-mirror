## Default

Use popup select to let people filter through a list of actions where limited space is a concern for
the trigger.

<Example
	Component={SelectPopup}
	packageName="@atlaskit/select"
	featureFlagSwitchers={['motionInput']}
/>

## Hidden search input

Use the `searchThreshold` prop to hide the search input.

<Example Component={SelectPopupNoSearch} packageName="@atlaskit/select" />

## Checkbox options

Enable checkbox options and multi select using the checkbox option component and `isMulti` prop.

<Example
	Component={SelectPopupCheckbox}
	packageName="@atlaskit/select"
	featureFlagSwitchers={['motionInput']}
/>

## Placement

Use `placement` to position the popup relative to the trigger.

<Example
	Component={SelectPopupPlacement}
	packageName="@atlaskit/select"
	featureFlagSwitchers={['motionInput']}
/>

## Layering

Currently there is no foundational platform solution that enables layered components to be composed
together without extra effort. Use the `offset` and `preventOverflow` props from
[popper](https://atlaskit.atlassian.com/packages/design-system/popper) to keep them in view as a
stop-gap.

<Example
	Component={SelectPopupModalExample}
	packageName="@atlaskit/select"
	featureFlagSwitchers={['motionInput']}
/>

## Content without portal

By default, the PopupSelect content is rendered inside `React.Portal`. Use
`popperProps={{ strategy: 'fixed' }}` prop to render the content directly after the trigger element.

<Example
	Component={SelectPopupWithoutPortalExample}
	packageName="@atlaskit/select"
	featureFlagSwitchers={['motionInput']}
/>
