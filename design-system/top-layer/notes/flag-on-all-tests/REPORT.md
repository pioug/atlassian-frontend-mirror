## Method

1. **Harness.** One commit per product forces the two gates. Each one wraps the existing resolver or
   gate mock, so every other gate resolves as before, and an explicit per-test override still wins.
   See `harness.md` for the mechanism, opt-out and uncovered runners per product.
2. **A/B on CI.** The control branch is the same 16 commits plus one commit that renames each newly
   forced gate to a gate that does not exist. The test selection is identical, and the gates resolve
   as on master. A failure on both branches is inherited.
3. **Triage.** 11 agents read every failing test and its components (no local runs). Each row has a
   category, a cause with `file:line`, a fix type and a confidence. 5 harness agents and 11 triage
   agents were used.
4. **Merge.** `aggregate.py` maps each row to one work chunk. Data: `all-failures.tsv` (column 1 is
   the chunk id). Per-chunk notes with more evidence: `triage/out/<triage-chunk>.notes.md`.

Caveats:

- **Static triage.** No test was run locally. Rows marked `low` need a run before anyone edits them.
- **Known-flaky noise.** Flakinator drops known-flaky tests before it decides a step result, so the
  control run can hide them. They are in `triage/known-flaky.tsv`. Agents judged each on the
  evidence. Some are flag-caused (they were learned from the earlier flag-on branches).
- **platform Playwright control coverage.** The control ran 30 integration shards and the flag run
  56, so "green on control" is not proven for every platform spec.
- **Chunk mapping is rule-based.** A row can sit in a near-neighbour chunk. Each chunk agent must
  read its rows and move any row that does not fit.

## Work chunks

Order: the decisions are made (2026-10-29), so nothing is blocked. Start with the design-system and
harness chunks, because they make many test failures go away. Then the test-only chunks, per
product.

**Rule for every chunk:** put all source changes (design system and product) behind
`platform-dst-top-layer`. With the gate off, behaviour stays as on master.

Find a chunk's rows: `awk -F'\t' '$1=="<chunk id>"' all-failures.tsv`.
