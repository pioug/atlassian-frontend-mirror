# Blanket

A blanket covers the underlying UI for a layered component, such as a modal dialog or a tooltip.

**This package is deprecated.** Blanket is not in the browser top layer, so tooltips, popups, flags
and dialogs show above it. Use `@atlaskit/modal-dialog`, `@atlaskit/drawer` or `@atlaskit/popup`
instead. See the [usage guidelines](https://atlassian.design/components/blanket/usage) for which one
to use.

## Installation

yarn add @atlaskit/blanket
