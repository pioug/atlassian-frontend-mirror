## Props

Filter button supports Button props except `appearance`, which is always `default`. `trailingMetric`
accepts a `number` or `string`. Use `0` to display zero, pass a formatted value such as `"99+"` to
abbreviate a count, or omit the prop to hide it. The count is built in, so you don't need a Badge
import or a separate Badge appearance.
